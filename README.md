An immersive, retro-futuristic command terminal and web OS inspired by classic cyberpunk aesthetics, sci-fi command centers, and high-tech user interfaces. 

Designed as a standalone, lightweight web experience, **CYBER // CORE** brings together interactive WebGL 3D graphics, procedural Web Audio synth synthesis, real-time audio visualizers, and tactile micro-interactions—all within a single web framework.

---

## 📸 Key Features

* **3D Holographic Neural Node:** Real-time WebGL particle sphere built with Three.js that dynamically shifts camera perspective and lighting in response to mouse movement.
* **Procedural Web Audio Synthesizer:** Real-time acoustic feedback generation triggered by user clicks and dragging across the terminal canvas.
* **Audio Frequency Visualizer:** Integrated HTML5 Canvas visualizer rendering live audio waveform dynamics.
* **3D Perspective Tilt Cards:** Hover-responsive UI panels featuring real-time perspective tilts (`rotateX/rotateY`) and cursor-tracking specular sheens.
* **Dynamic Island Status HUD:** Expandable top status bar pill providing real-time system metrics, FPS performance tracking, and node status.
* **Tactile Micro-Interactions:** Magnetic glass control dock buttons, dual-ring spatial cursor with custom hover physics, and live telemetry tracking.

---

## 🛠️ Tech Stack & Technologies

* **HTML5 & CSS3:** Semantic markup with CSS custom properties, grid layouts, and advanced `backdrop-filter` glassmorphism.
* **Vanilla JavaScript (ES6+):** Lightweight component orchestration without dynamic framework bloat.
* **Three.js (r128):** WebGL rendering engine powering particle geometry and interactive 3D camera physics.
* **GSAP (GreenSock Animation Platform):** Smooth spring physics and micro-interaction animations.
* **Web Audio API:** Native browser audio synthesis for interactive sound design.
